# منصة أفق التعليمية

منصة تعليمية عربية لإدارة المدرسة وفق المنهج اليمني للصفوف من الأول إلى الثاني عشر.

## التشغيل

افتح `login.html` مباشرة في المتصفح، أو استخدم أي خادم ملفات محلي.

## الحسابات التجريبية

كلمة المرور لجميع الحسابات: `123456`

- المدير: `admin`
- المعلم: `teacher`
- الطالب: `student`
- ولي الأمر: `parent`

## الوحدات

لوحة المدير، الطلاب، المعلمون، أولياء الأمور، الصفوف 1–12، المواد والمناهج، التقارير، الحضور والغياب، والجدول الدراسي.

> هذه نسخة واجهة أولية تستخدم بيانات تجريبية و`localStorage`، وليست بديلاً عن خادم وقاعدة بيانات في بيئة الإنتاج.
